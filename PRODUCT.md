# Party Paper

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Adults organizing gatherings, birthdays and office events.

## Product Purpose
Create unique printable bingo cards and word searches with an answer key.

## Capabilities and Constraints
Existing native ES module application deployed on GitHub Pages. Processing is local; there are no accounts, analytics, third-party requests, advertising or external APIs. Preserve the existing core algorithms and export behavior. The owner requested distinctive UI/UX and characteristic animation for both apps, with deployment and review.

## Evidence on Hand
Working source in app.js and core.js, automated tests in tests/, illustrative sample input. No testimonials or commercial traction claims.

## Accessibility & Inclusion
Keyboard controls, labeled inputs, visible focus, live status, reduced-motion alternatives and responsive layout.

## Open Decisions
Advertising approval, analytics and unattended agent operation remain outside this release.
