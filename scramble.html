Word scramble: printable game and host guide

1–12 players · 5–10 minutes · solo or pairs

An anagram puzzle with scrambled letters, writing space and a separate answer key. This pack uses celebration vocabulary, so it works as a quiet arrival activity.

Make this game

How to play

  1. Choose familiar words of 3–16 English letters. Generate and inspect the puzzle before printing.
  2. Print one player sheet per person or pair. Keep the answer key separate until everyone is finished.
  3. Give five to ten minutes, or play without a timer. Players rearrange all the letters to recover each word.
  4. Reveal the answers together. Accept other valid words using exactly the same letters if your group agreed to that rule before play.

Set up the printable

One word per line, 3–16 English letters. Spaces and hyphens are removed; duplicate words are combined.

Choose “Make my printables”, inspect every preview sheet, then use “Print / Save PDF”. Player pages appear first and any answer keys follow. In your print dialog, choose only the player page range for guests.

Make it work for your group

For younger players, use short words and provide a theme hint. Let pairs work together rather than score individuals when vocabulary levels differ.

Host notes

Some words have more than one valid anagram. A theme makes the intended answer clearer, but the host should still handle alternatives fairly.
