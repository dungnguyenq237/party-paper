# Security, privacy and reliability

This assessment covers guest rooms and optional extensions. Production defaults to private rooms, short-lived aliases, prewritten game content, no open chat and no external advertising in play. The baseline printable generator keeps user content on-device. Rewrite scope-specific privacy copy before networked play launches.

| Boundary | Failure or exposure | Required control and verification |
|---|---|---|
| Join and identity | Guessable human codes, seat farming or reuse of a display name | Random high-entropy (128-bit) invite capability in URL fragment · human-friendly 8-character random code, normalized nonambiguous alphabet, collision-safe creation, rate limits and optional host approval/lock. A code permits a join request only. Hash session tokens, rotate on grant, bound by expiry. Never reclaim by alias. Lock curated/paid events to tickets and active roster. |
| Upgrade and membership | Wrong origin, stale sessions or a projector gaining control | TLS, exact Origin allowlist, same-site secure cookies, CSRF protection for writes, one-use short ticket, role check for every operation, revoke sockets on leave/kick, explicit display-only scope. Prevent invitation referrers and clear fragments after exchange. |
| Commands | Invalid fields, replay, late orders, contested inventory | Parse bounded schemas before dispatch, enforce server-derived viewer/seat, phase/version/ownership/resource checks, transactional receipts and deterministic deadline policy. Test with synthetic sessions against local fixtures, verify no mutation on rejection. |
| Hidden state | Clue/role leaks through host screens, logs, error responses, static bundles, source maps or shared caches | Serialize from positive viewer allowlists · no omniscient payloads filtered by browser. Private prompts/solutions stay off public git and build output unless intentionally public sample. No debug dump, shared room cache or private identifier in social images. Per-recipient fixtures and artifact checks are release gates. |
| Untrusted text and packs | Unsafe markup, injection or impersonating official guidance | Normalize/bound lengths, enum options, parameterized SQL, no HTML rendering for aliases/arguments, contextual escaping for static content and metadata, restrictive CSP, no user-supplied URLs or dynamic module paths. Validate and license editorial packs. Reject unsupported media. |
| Availability | Burst joins, slow consumers, large snapshots and stalled timers | Start with create 5/min per short-lived network bucket, join 20/min per bucket with additional per-room limits, normal actions 5/s per seat, <=8 KiB command, queue bound and backpressure. Shared venue NAT requires a rehearsed per-event admission lane and sufficient burst tokens for validated guests. Set exact lane quota from load results. Never enforce a normal household cap against all guests behind the same venue IP. |
| UGC and safeguarding | Humiliation, unwanted audio, abusive aliases, unwanted disclosure | Fictional prompts by default, private rooms, pass/replace/mute, host remove/lock, conceal flagged copy, clear report path without public reposting. No targeting protected traits, employer performance scoring or real personal accusations. Before custom/community packs, fund review, appeal, takedown and repeat-abuse handling. |
| Secrets, AI and optional purchases | Provider tokens in browser, unlimited cost, untrusted model output or duplicated payments | Environment-scoped credentials only on server · secrets manager/host config, redacted logs, rotation owner. Strict quota reservation before a call, allowlisted model, no tools or data access, input/output moderation, output as plain text, objective scoring local. Verify provider webhooks and deduplicate grants/refunds before enabling sales. |
| Failure and recovery | Displays disagree or stale backup resurrects a room | Commit before broadcasts, expire on read and startup, room version pinned, reconnect to authoritative snapshot, discard all transient rooms and invalidate guest credentials on lost-volume/stale restore, not just markers from the older backup. Use an isolated synthetic rehearsal. Printable tool and instructions remain available if the live service fails. |

## Media consent and deletion contract

Explain who can hear each hop, whole-room reveal, withdrawal, automatic deletion and that another participant may independently record playback. Require active consent for this match, display a visible recording indicator and stop actual capture at 8 s. Default to text on permission failure before start. Grant read access only for an authorized predecessor hop or the post-game reveal. Use an authenticated stream or single-use, short-expiry grant with an authorization check on fetch. Disable caching and range leakage outside the same permission. Validate actual container/content/duration and strip or reject unexpected metadata. No transcript service, recording download, public link or support attachment by default.

Deny reads immediately on withdrawal, room expiry or end-of-results. Delete bytes as soon as the reveal closes, with an absolute 1 h lifetime after upload and a 5-minute cleanup sweep. Track access expiry and physical deletion separately. Monitor oldest unreaped file. Mark a deletion pending until the store confirms, retry idempotently and page the operator at >10 min overdue. Delete partial uploads and orphans as well. Choose non-backed-up ephemeral storage or independently verified storage lifecycle. Never place voice bytes in room DB snapshots. Do not promise that a local copy someone already heard can be recalled. Avoid collecting participant emails to process deletion. Provide a per-seat delete control and private support contact.

Room snapshots, receipts, aliases and posted arguments have the room's TTL. Purge live tables and WAL/checkpoint per operational limits. Verify provider-level snapshot/log retention before making a public deletion promise. Exclude transient room/session/media state from application-managed commercial backups. Provider snapshots can retain encrypted deleted data for seven days; prohibit restoration into active guest service, disclose retention. Logical TTL/deletion is not forensic erasure of disk/WAL/snapshots. Encrypt durable storage/backups and restrict operator access. Define permitted ages, guardian/venue responsibilities, jurisdiction and cross-border hosting with qualified local review, before school, youth or commercial audio deployment. Document access/deletion response owner and incident contacts. A proposed adult-hosted pilot uses no targeted advertising. [Data lifecycle](ARCHITECTURE.md) · [Analytics](ANALYTICS.md)

## Independent review hardening (IR-C01, IR-C02, IR-H02, IR-H04)

Fence queued commands on kick/leave/reconnect/host change/expiry. Test stale sockets, two tabs, ticket replay, invalid Origin, digest conflicts and overload. Limit pre-auth sockets/IP, frame/decompression/depth, alias/argument/grant sizes and room aggregate state. Host-only __Host- cookie (Secure, HttpOnly, Path=/, no Domain), CSRF including bootstrap, no-referrer and replaceState for invitation fragments before third-party code. No flagging seat or report/kick reason broadcast. Conceal flagged text from future projections/render caches; cannot recall earlier copies. Actual private report contact, age/audience policy and operator before external pilot. Scoped CSP, no private payload/log/cache.
