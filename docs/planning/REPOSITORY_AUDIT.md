## Reproduction and open evidence

From an isolated checkout run `git ls-files`, `npm ci`, `npm test`, `npx playwright install chromium` and `npm run test:e2e`. On Node 24.22.3 the local Node suite passed 58/58, including the posttest SEO build. GitHub also reports a successful [application check on the audited SHA](https://github.com/dungnguyenq237/party-paper/actions/runs/44835568172). The test strategy records browser evidence and future acceptance criteria. [Testing](TESTING.md)

**Unknowns include** the monthly host invoice, access-log retention, traffic geography, p95 latency, search/ad account status, audience size, legal operator, ownership of a custom domain, installed venue networks and editorial capacity. A successful HTTP request measures reachability from one vantage point only. **Validation requires** inspecting operator settings and bills, obtaining opt-in pilot evidence, rehearsing a domain transition and measuring bandwidth and browser/device behavior before pricing or making capacity commitments.
