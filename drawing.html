Drawing challenge: printable game and host guide

4–16 players · 20 minutes · teams of 2–4

A drawing-and-guessing game built around playful combinations. Art skill is not the point: the fun comes from how differently people interpret a prompt.

Make this game

How to play

  1. Print and cut the prompt cards. Give each team scrap paper and a thick pen; keep the prompts hidden.
  2. A drawer takes one card and has 90 seconds to draw. No letters, numbers, spoken clues or gestures.
  3. Teammates can guess throughout the turn. Give one point when they identify the main idea; agree before play whether close wording counts.
  4. Rotate the drawer every turn. Finish after each person has drawn once, using equal turns for all teams.

Set up the printable

One drawable idea per line. Print the cards, then supply blank paper separately.

Choose “Make my printables”, inspect every preview sheet, then use “Print / Save PDF”. Player pages appear first and any answer keys follow. In your print dialog, choose only the player page range for guests.

Make it work for your group

For a cooperative version, remove the timer and let everyone help guess. Let players describe the picture instead of drawing if a motor or vision limitation makes the original format inaccessible.

Host notes

Use larger paper for a big group. A single pen shared by all teams creates a bottleneck; prepare a drawing station for each team.
